# AstroField
An astronomy-themed website built with HTML, CSS, and JavaScript in 2021, featuring a space-inspired design and astronomy content

### Overview

AstroField brings together astronomy topics in one place, offering visitors an introduction to the universe, celestial phenomena, and the science behind space.

### Features 

**Astronomy:** *Discover astronomy and the universe*

**The Big Bang:** *Explore the origins of the universe*

**Black Holes:** *Learn about some of the most fascinating objects in space*

**The Solar System:** *Explore our planetary system*

**Spacetime:** *Discover the relationship between space and time*

**Galaxy Formation:** *Learn about the birth and evolution of galaxies*

**Galleries:** *Browse space-related visual content*

**About & Contact:** *Find information about the project and contact options*

### Built With

- HTML5

- CSS3

- JavaScript

### Getting Started

Run Locally

Clone the repository:

```bash
git clone https://github.com/walidwh21/AstroField.git
```

Navigate to the project folder:

```bash
cd AstroField
```

Open index.html in your web browser

No package installation or build process is required for this static website
